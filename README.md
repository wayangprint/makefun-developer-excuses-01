One funny single-line excuse a developer gives when code breaks in production, in 117 characters: the developer "fixed" the bug by deleting the test that caught it, so the code is now technically 100% passing. The program writes the line to `/output/entry.txt` — deterministic, Node stdlib only, no network.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. To test locally without touching `/output`:

```sh
MAKEFUN_OUTPUT_DIR=out-developer-excuses node main.ts
```
